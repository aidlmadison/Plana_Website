# Evaluation inbox

Copy a whole completed `evaluation_<date_time>` folder here, unchanged, then click **Check import folders** in the instructor portal (or restart the server). No `latest.json`, renamed files, or per-student restructuring is needed.

For a hosted website, upload the same run ZIP through **Import evaluation ZIP**. PDFs, imports, credentials, and the review database are private runtime data, ignored by Git. Keep `PLANA_DATA_DIR` on persistent storage between deployments. Earlier `data/imports` handoffs still work.
